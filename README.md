# MI&IN Admin

Main admin app for MI&IN GLOBAL IMPORTERS.

## Run

```bash
cd admin
npm run dev
```

Default URLs:

- Admin dev server: `http://localhost:8081/admin/`
- Admin preview: `http://localhost:4174/admin/`

## Build

```bash
cd admin
npm run build
```

## Connected with storefront

When the storefront dev server is running on `http://localhost:8080`, it proxies `/admin/` to this admin app.

- Storefront: `http://localhost:8080/`
- Connected admin path: `http://localhost:8080/admin/`
